# AIORBITLAB Web

Website AIORBITLAB berbasis Next.js App Router dengan TypeScript, React, dan Tailwind CSS.

## Stack
- Next.js 16
- React 19
- TypeScript 5
- Tailwind CSS 4

## Development
```bash
npm install
npm run dev
```

## Production check
```bash
npm run typecheck
npm run build
```

## Deploy
Project siap dideploy ke Vercel dari branch `main`.
